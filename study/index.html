Help improve the scheduler

Every material here schedules you with a memory model, and the only way to tell whether it is any good is to set what it predicted against what actually happened. With this on, each review sends an anonymous line: which question was asked, the grade, how long you took, and the model's own numbers at that moment. Visibility & locks

Hidden keeps an item off the list for viewers. Locked also withholds its decryption key, which is what actually stops a viewer from reading it. Retired keeps it openable but moves it under a collapsed heading at the bottom: for an older quiz or assignment.

Change a code

Changing a code signs out every other device using it. At least 10 characters; use something long.
