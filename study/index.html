What is sent

Every material schedules you with a memory model, and the only way to tell whether it is any good is to set what it predicted against what actually happened. With this on, each review sends an anonymous line: which question was asked, the grade, how long you took, and the model's own numbers at that moment. Each visit also notes when a page opened and closed, how long it was in front of you, the tab it was on, any error it hit, and a rough description of the browser (like "iPhone, Safari 18"), so a broken page or a confusing screen shows up. After a quiz you may be asked, once, how it went (a score is sent only if you type one in). It never sends your name, your codes, or anything you typed in a material, and it all waits on this device until there is a connection.
